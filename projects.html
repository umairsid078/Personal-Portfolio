My Projects

Introduction to Networks - Design Project

Course: INFR1411U - Introduction to Networks
Instructor: Ayda Roknaldin

I designed an IPv4 addressing scheme for a three building network using VLSM. Each building had a different number of hosts, so I created subnets that met each building's needs without overlapping.

Choose Your Own Adventure Game

Course: INFR1101U - Introduction to Programming for IT

I created a terminal-based choose your own adventure game using Python. The player makes different choices throughout the story, and those choices change what happens next and how the game ends.

Investra Portfolio Tracker

I worked on a personal finance website called Investra. The goal of the project is to let users keep track of investments from different accounts and view their holdings in one place.
